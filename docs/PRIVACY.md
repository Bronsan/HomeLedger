# 隐私与数据位置

一句话：**物品数据默认只在本机；账号服务器只保存登录所需的最少信息，不采集行为画像。**

这份文档同时回答两个常被混在一起的问题：

1. 软件安装后，数据到底缓存在哪里？
2. 登录服务器上到底存了什么，没存什么？

---

## 1. 三种模式，数据在哪里

| 模式 | 物品/照片存在哪 | 是否必须登录 | 服务器能读到什么 |
| --- | --- | --- | --- |
| **仅本机** `local` | 当前设备的 IndexedDB | 否 | 不连接服务器，什么也读不到 |
| **本机 + 加密同步** `sync` | 每台设备各一份完整副本 | 是 | 同步索引的明文字段 + 敏感字段/照片的密文 |
| **直连服务器** `remote` | 服务器数据库 | 是 | 该家庭存在服务器上的完整数据 |

打包的 Windows / Android 应用默认是「仅本机」。浏览器打开服务器地址时默认是
「直连服务器」，因为浏览器没有本地库；可以在「设置 → 同步」里改成「本机 + 加密同步」。

> 同步模式不是「把明文上传到服务器」。名称、编号、分类、位置等列表页需要的低敏感
> 字段是明文索引；描述、序列号、价格、购买渠道、备注、借用人联系方式、全部照片和
> 附件都是密文。服务器端没有解密路径。详见 [LOCAL_FIRST.md](LOCAL_FIRST.md)。

## 2. 账号服务器存什么

只有当你在客户端里连接一台账号服务器并注册/登录时，服务器才会保存：

| 字段 | 用途 | 是否必填 |
| --- | --- | --- |
| 邮箱 | 登录标识 | 是 |
| 密码哈希（scrypt，不可逆） | 验证登录 | 是 |
| 显示名 | 账号上的称呼 | 是 |
| 注册时间、最后登录时间 | 账号状态与安全排查 | 自动 |

**家庭关系、成员角色、自定义头像和物品数据不在账号服务器上。** 它们只存在用户
自己的数据服务器（或本机资料库）里；账号服务在代码层面不装配这些路由，也拒绝
头像上传。账号服务与数据服务器可以是两台完全不同的机器。

此外，操作审计只记录「谁在什么时候改了什么」（操作者、动作、变更前后），
**不记录 IP 地址、User-Agent、设备指纹、定位、通讯录或使用行为**。应用进程和示例
反向代理配置都关闭了访问日志；Caddy/Nginx 只保留错误日志。

注册人数是从 `users` 表实时统计的**总数**，只排除尚未设置密码的邀请占位账号。
公开接口 `GET /api/v1/system/stats` 只返回一个整数，不返回任何账号、邮箱或 ID。

## 3. 安装后缓存具体在哪

### Windows（安装版 / 便携版相同）

| 内容 | 路径 |
| --- | --- |
| 程序文件 | `%LOCALAPPDATA%\HomeLedger`（安装版；便携版是你解压的目录） |
| 内置服务数据库、附件、备份、日志、`.secret_key` | `%APPDATA%\HomeLedger` |
| WebView2 的 localStorage / IndexedDB / 缓存 | `%LOCALAPPDATA%\app.homeledger.desktop\EBWebView` |

**数据库不在安装目录里。** 这是有意设计：安装目录可能只读、覆盖升级会替换文件，
而用户数据必须独立于程序版本。便携版也不会把数据库写在 exe 旁边，原因相同。

在文件资源管理器地址栏直接粘贴 `%APPDATA%\HomeLedger` 即可打开数据目录。

### Android

APK 安装在系统应用目录；数据在应用私有沙箱内（`/data/data/app.homeledger.desktop/`
附近，普通用户和电脑都无法直接访问）。卸载应用即删除；系统备份是否包含它取决于
手机厂商的备份设置。

### macOS / Linux

| 平台 | 数据目录 |
| --- | --- |
| macOS | `~/Library/Application Support/HomeLedger` |
| Linux | `$XDG_DATA_HOME/homeledger`（通常是 `~/.local/share/homeledger`） |

### Docker / CentOS 服务器

容器内固定是 `/data`。宿主机上由 `HOMELEDGER_DATA_VOLUME` 决定：

- 命名卷（默认 `hl-data`）：`/var/lib/docker/volumes/hl-data/_data`
- 宿主机目录：例如 `/srv/homeledger/data`，数据库是 `homeledger.db`

## 4. 怎么清除

### Windows

1. 正常卸载，并在卸载向导里勾选「删除应用程序数据」。
2. 如果没勾选，或想手动清干净，删除下面两个目录：
   - `%APPDATA%\HomeLedger`
   - `%LOCALAPPDATA%\app.homeledger.desktop`

   第一个是内置服务数据库/附件/备份，第二个是 WebView 的本地库与缓存。两步都做才
   算干净；只删一个会留下另一半。

### Android

在系统设置里卸载应用。需要先保留数据时，先在应用内导出备份。

### 浏览器 / PWA

在浏览器设置里清除该站点的数据（Cookie、Local Storage、IndexedDB）。

### 服务器

```bash
# 停服务后删除数据目录；这会删除该实例的全部家庭与账号，不可恢复
docker compose down
sudo rm -rf /srv/homeledger/data/*
docker compose up -d
```

删除前先确认备份已经拿到，并且不是删错实例。

---

## 5. 关闭自助注册

家庭成员都注册完成后，可以在 `.env` 里把：

```env
HOMELEDGER_ALLOW_REGISTRATION=false
```

然后 `docker compose up -d`。之后新成员只能由管理员在「成员」页面邀请；需要再开放
注册时改回 `true` 再重启。

## 6. 我们刻意没做的事

- 没有第三方统计 SDK、埋点、崩溃上报或广告 SDK。
- 没有手机号、真实姓名、身份证、地址、定位、通讯录、相册全量扫描。
- 没有设备指纹；账号不绑定 IMEI、MAC 或广告 ID。
- 没有把物品数据默认上传到任何服务器；同步必须由用户主动开启。
- 没有在安装包里内置演示账号、测试用户或示例密码。

如果未来加入任何会离开设备的数据通道（例如云端 OCR），界面会在使用前明确提示，
并默认保持关闭。
